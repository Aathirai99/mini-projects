**Tic-Tac-Toe**
Two-player game in the terminal with turn switching, input checks, and win and tie detection.
Built with dicts, loops, and functions, and it asks to play again at the end.

**Contact Book**
Command-line app to add, search, list, and delete contacts, saved to a JSON file.
Handles bad input without crashing and ignores upper or lower case in names.
